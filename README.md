# KulinerBunta.id

Aplikasi web terpadu 4 portal (Pembeli, Merchant UMKM, Kurir Lokal, dan Admin Governance) untuk Kecamatan Bunta, Kabupaten Banggai.

## Akun Uji Coba
- **Merchant UMKM:** `merchant` / `bunta123`
- **Kurir Lokal:** `kurir` / `bunta123`
- **Admin Governance:** `adminbunta` / `Bunta2026!`

## Deploy
Unggah seluruh file di paket ini ke repositori GitHub Anda lalu hubungkan ke Netlify atau GitHub Pages. Untuk sinkronisasi lintas perangkat, jalankan `supabase-schema.sql` di SQL Editor Supabase dan masukkan URL + Publishable Key pada menu **Admin → Pengaturan**.
